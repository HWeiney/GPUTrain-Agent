# GPUTrain Agent 项目面试考点

本文档随项目开发同步维护。只有已经在代码、测试或部署中完成验证的实现，才会作为项目事实写入回答；规划中的能力必须明确标记为规划，不得作为简历成果。

每个考点统一记录：

1. 问题。
2. 核心回答。
3. 项目中的具体实现。
4. 关键代码与测试位置。
5. 常见追问。
6. 容易答错的点。
